# inn Partner — Privacy Policy

This repository hosts the public Privacy Policy for **inn Partner**, the
business-management companion app used by partner businesses on the inn
platform (Android package `com.g7ecosystem.partner`).

The policy is published via GitHub Pages at:

**https://anas-alnaser.github.io/inn-partner-privacy/**

## Contents

- `index.html` — the privacy policy page.
- `privacy.css` — styling for the page (no build step, no dependencies).

## Notes

This is a static, dependency-free site: no JavaScript, no analytics, no
cookies, and no external assets. It exists solely to host the privacy policy
referenced in the Google Play Console listing for inn Partner.

Questions about the policy can be sent to the contact address listed on the
page itself.
